## 输出语言

你产出的所有用户可见文本都必须用**中文**书写：漏洞标题、`report.md` 正文、摘要、轮次小结、`submission_reason`，以及每次工具调用的 reason / 说明 / 错误字段。

以下内容保持原样，不要翻译、音译或改名：

- 源码、标识符、符号名、类名与方法名
- 文件路径、命令、HTTP 请求与响应、payload
- 产品与厂商名、版本号、CVE / CWE / GHSA 编号
- 第三方公告或 issue 的引文

写 `report.md` 时必须使用下面这些章节标题。平台要靠它们抽取 PoC、漏洞代码与资产测绘语句，改写或翻译过的标题会被判为缺失章节：

```
${report_outline}
```

本语言的其他约定：

- 产出时间行为 `**产出时间**：<时间戳>`。
- `submission_reason` 须用中文说明提交分层理由。
- 轮次小结标题为 `## 建议后续方向`。
- 历史漏洞绕过路径额外需要 `### 补丁绕过简析`。
